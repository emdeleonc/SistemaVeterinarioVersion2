# Sistema de Control Clínico Veterinario v2

Proyecto final de Programación II, Universidad Mariano Gálvez.

## Qué hace

Es un programa de consola en C# para llevar el control de una clínica veterinaria. Permite registrar propietarios, mascotas, insumos y consultas, y para cada uno se puede crear, ver, actualizar y eliminar (CRUD).

Todos los datos se guardan en una base de datos SQLite, así que no se pierden al cerrar el programa.

## Cómo se ejecuta

1. Instalar el SDK de .NET 10.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar:

```
dotnet run
```

La primera vez descarga lo necesario y crea la base de datos automáticamente. Después aparece el menú: se escribe el número de la opción y se siguen las instrucciones en pantalla.
